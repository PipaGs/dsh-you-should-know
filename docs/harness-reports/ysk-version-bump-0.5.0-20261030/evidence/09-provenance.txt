### redaction note

All captured logs were filtered on capture through exactly this expression:

  sed -E 's#file:///Users/[^/ ]+#file://<worktree>#g; s#/Users/[^/ ]+#/<home>#g'

The expression rewrites the home SEGMENT, not the whole worktree prefix: an absolute
file URL such as file:///Users/<account>/work/<repo>/test/x.js becomes
file://<worktree>/work/<repo>/test/x.js. For example, the 02 stack traces read
file://<worktree>/work/dsh-you-should-know/test/release-consistency.test.js. Any other
home-anchored path becomes /<home>/ followed by the remaining segments.

This is an on-capture redaction of evidence. No path was rewritten after the run, and no
exit code, test count, or failure message was altered. Files 01-07, 10-13, 03b, 04b, 06b,
and the final report contain no absolute workstation path; the scan in 08 confirms that
over exactly those files.
